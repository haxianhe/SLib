# AI 漫剧与影视短片

把创意推进到可交接的镜头素材和成片。默认分工：Codex 编写剧本与提示词、调用可用图片生成能力；即梦 / Seedance 生成镜头视频；剪映审核、精修和导出。尊重用户指定工具，只完成当前请求的阶段。

## 入口与范围

- 先读取用户已有方案、剧本、参考图和项目约定，复用已确定的风格与工具，不重新询问已知信息。
- 最小输入是创意或已有故事。缺少会改变内容的主题时提问；时长、比例、风格等可先给建议并标注假设。提供方案时不要求用户先开通 API。
- 无既定规格时，建议先做 30–60 秒、1–2 个角色、1–2 个场景的试片；这是起步建议，不限制用户的目标。
- 只写剧本或提示词时直接交付文本；需要落盘时优先使用用户指定目录，否则在当前项目内使用 `productions/<作品名>/`，先检查已有文件。不要硬编码个人机器路径。

## 五步制作流程与前置产物

默认顺序：**剧本与分镜 → 角色与分镜画面 → 图生视频 → 配音与音效 → 剪辑成片**。先辨别普通对白漫剧、音乐／对唱作品及用户只要求的局部阶段，再据实际素材推进。用户提供的合格产物可以复用，不从头重做。

阶段验收是检查真实产物和依赖，不是要求用户逐步重复批准。已有授权范围内连续推进；遇到未授权生成、缺失前置素材或未核实的工具能力时，交付已完成部分和具体缺口，不把下一阶段写成已就绪。角色参考图、文字分镜、分镜图片、镜头视频是不同产物，不能互相替代。

### 1. 剧本与分镜

- 确定题材、人物目标、核心冲突、开场钩子、转折与结局，输出分场剧本和对白／歌词。历史题材分开记录史实、来源分歧、演义与原创，不把虚构对白写成引文。
- 明确目标时长、画幅、画风及工具选择，未定值写成建议。片头、字幕、停顿和收尾都计入总时长，不能只靠镜头秒数相加判断故事或台词能否成立。
- 拆成稳定镜头 ID；每镜写清人物、画面内容、动作、景别、机位、视线、场景、光线、运镜、声音与大致时长。“一句台词一镜”可作起步方法，按动作与叙事需要调整，不强制机械对应。
- **交付与门槛：**形成可执行剧本和覆盖全片的文字分镜。暂估秒数标为预排，不能声称已按实际音频定轴。只有创意、人物名或长段视频 prompt 时，先补齐此步。

### 2. 角色与分镜画面

制作素材或交接包时读取 [references/shot-handoff.md](references/shot-handoff.md)。

- 先固定角色脸型、发型、年龄感、服装、比例、配色及画风；为角色、场景和道具分配稳定 ID。按实际需要建立正侧面、全身、表情与场景参考，不把每种参考视图都变成固定必做数量。
- 再按文字分镜逐镜写图片提示词：**主体＋动作／姿态＋场景＋景别＋机位＋光线＋风格**，引用选定人物及场景版本，生成并审核对应的分镜图片。人物定妆图只固定身份，不能代替具体镜头构图。
- 检查脸、手、服装、道具、视线、屏幕方向、光线与相邻镜头空间关系，记录实际选用图片及审核状态；复杂动作按需准备首尾帧或补充关键帧。
- 用户授权出图且工具可用时，使用对应图片生成技能完成实际出图；工具不可用或只要求提示词时交付文本并标记图片未生成。不要把 `image-prompt-*` 的“只产 prompt”限制套到本 skill。
- **交付与门槛：**角色／场景参考已选定，计划制作视频的镜头已有实际可用、已检查的分镜图片。缺图时停在画面阶段，不从一张人物参考图直接跳到整集视频。用户明确选择纯文生视频或原生整片生成时，可采用另一条路线，但先说明它改变了图像控制方式，不能称已完成逐镜分镜图。

### 3. 图生视频

- 以选定分镜图作为首帧或对应参考输入，再写独立的视频提示词：动作时序、表情、运镜、节奏和必须保持的外观。优先小动作、呼吸、眼神与慢推拉，复杂多人交互按需拆镜。
- 核对实际入口的首帧／多参考／音频参考／口型能力以及单次时长，不能把某入口的上限推广为所有模型规则。镜头数量、分镜图数量和生成任务数分别计算，不因整片恰好落在一次时长上限就跳过分镜图。
- 精确口型、演唱或动作卡点需要已确定的声音时，先落实相应音频；否则可先制作基础动作，后续再做经工具能力核实的声音与口型处理，不承诺事后自动对齐。
- **交付与门槛：**镜头视频实际下载、可解码，人物与动作连续性经检查；图片或任务已受理不等于已有动态镜头。未验项如实标注。

### 4. 配音与音效

- 将定稿台词交给用户选择的声音工具，固定各角色音色，生成并试听发音、情绪、气口、时长和字尾；再配置 BGM、环境声与音效，保持人声清楚。
- 分别核对普通语音合成、歌曲演唱、原创旋律、双声部及口型能力。配音功能存在不证明能唱指定歌词，`generate_audio` 也不保证演唱准确；不能把朗读、歌词文本或提示词称为已完成歌曲。
- **交付与门槛：**实际可播放并经试听的角色声音／歌曲及所需音乐音效已就绪；用实际音频修订镜头切点与字幕，不能靠截断字尾凑时长。

#### 音乐／人物对唱的依赖调整

仍先完成歌词与文字分镜初稿，再尽早确定音乐、演唱方案并取得实际音频，按演唱分句与节拍锁定分镜时点；角色与场景参考可以并行准备。音频通过后再定稿逐镜分镜图及动态卡点，不能以“音频优先”为由省略第二步。第四步在此模式负责声音复核、补充音效与混音，不重复生成主歌曲。

### 5. 剪辑成片

- 在剪映等用户选定工具中按镜头顺序组接视频，对齐实际人声、BGM、音效和字幕；转场重叠、片头片尾及尾音均计入最终时间线。
- 无既定导出规格时可建议 1080P、30fps；用户已定规格优先。记录源素材帧率与导出帧率，重编码为30fps不等于原生30fps，不为追求参数擅自改变画幅或节奏。
- **交付与门槛：**分别验证草稿写入、应用打开、素材加载、最终导出和播放。未完成某项就明确缺口，不以素材清单、任意 JSON 或写入成功宣称已交付可用工程／成片。
- 剪映社区草稿工具不等于官方能力，未经系统与版本实测不承诺全程 CLI 导出。不支持自动导出时交付可用草稿或按序素材、字幕和操作指引；用户同意替代合成路径时可用 FFmpeg，不默默替换剪映。

## 工具执行与授权

实际调用 CLI / API 或讨论接入时读取 [references/automation.md](references/automation.md)，核对当前官方契约与本机帮助，不编造子命令、模型 ID 或鉴权参数。

区分即梦界面、即梦同源 API 和火山方舟 Seedance 服务；保留用户选定的执行入口。会员、模型开通、节省计划或提供密钥不证明目标入口可调用，也不单独构成生成授权。只要求流程、提示词或可用性判断时，不通过试生成来验证权限；用户要求未经允许不生成时，图片、语音、歌曲与视频均遵守该边界。已有明确授权的范围内继续执行，不重复索取许可。

提交前列清素材依赖、任务数量、参数、费用范围和尝试上限。为实际任务保存提示词、选定分镜图、候选版本、任务 ID 与状态。超时先查原任务，无法确认是否创建时标记 `unknown` 并停止该任务重提；下载失败先恢复下载。不得用新付费任务代替状态查询，也不无限重抽。

## 质量与交付状态

| 检查点 | 验收内容 |
|---|---|
| 角色与场景 | 脸、服装、画风、道具和空间关系连贯 |
| 动态镜头 | 无明显变形、闪烁、穿模、重复人物或动作中断 |
| 叙事与声音 | 镜头顺序、对白停顿、字幕时间与口型匹配 |
| 工程与成片 | 素材路径可解析；草稿能打开；导出视频可播放且有预期音轨与时长 |

只报告实际达到的阶段：剧本完成、提示词完成、图片已生成、视频已下载、草稿已写入、草稿已打开、成片已导出。未执行的检查标明未验证。

交付实际文件路径、选用镜头清单、缺失素材和下一步。生成素材时记录可用镜头数、尝试次数、已知费用与耗时；没有账单数据时不推算为实际费用。
