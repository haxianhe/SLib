# AI 漫剧与影视短片

把创意推进到可交接的镜头素材和成片。默认分工：Codex 编写剧本与提示词、调用可用图片生成能力；即梦 / Seedance 生成镜头视频；剪映审核、精修和导出。尊重用户指定工具，只完成当前请求的阶段。

## 入口与范围

- 先读取用户已有方案、剧本、参考图和项目约定，复用已确定的风格与工具，不重新询问已知信息。
- 最小输入是创意或已有故事。缺少会改变内容的主题时提问；时长、比例、风格等可先给建议并标注假设。提供方案时不要求用户先开通 API。
- 无既定规格时，建议先做 30–60 秒、1–2 个角色、1–2 个场景的试片；这是起步建议，不限制用户的目标。
- 只写剧本或提示词时直接交付文本；需要落盘时优先使用用户指定目录，否则在当前项目内使用 `productions/<作品名>/`，先检查已有文件。不要硬编码个人机器路径。

## 制作流程

### 1. 故事与视觉设定

输出故事梗概、冲突与结局、角色动机、分场剧本和对白。时长应容纳对白、动作和停顿，不能只靠镜头秒数相加判断。

明确 2D 漫画、3D 动画或写实风格、画幅和目标时长。为角色分配稳定 ID，固定脸型、发型、服装、比例和配色；为场景与道具分配 ID。建立正侧面、全身和表情参考，跨镜头持续引用。

### 2. 分镜与图片

制作素材或交接包时读取 [references/shot-handoff.md](references/shot-handoff.md)，按其目录和镜头记录组织输出。

- 每镜头表达一个主要动作或情绪变化，起步可按 3–8 秒拆分；多人交互、打斗和遮挡复杂时进一步拆镜。
- 分镜图明确角色、位置、视线、景别、光线与构图，检查相邻镜头的屏幕方向、道具与服装连续性。
- 图片提示词描述静态构图；视频提示词另写动作时序、表情、运镜、节奏与应保持的外观。不要把整集剧本塞入一条生成提示词。
- 优先用定稿图做图生视频或参考生成，先验证少量镜头再批量制作。
- 用户要求出图且当前有图片生成工具时，使用其对应技能与工具；只有提示词能力时交付提示词和参考要求，明确图片未生成。不要把相邻 `image-prompt-*` skill 的“只产 prompt”限制套到本 skill。

### 3. 镜头视频

实际调用 CLI / API 或讨论接入时读取 [references/automation.md](references/automation.md)。先核对当前可用工具、模型和官方契约；不凭记忆编造子命令、模型 ID 或鉴权参数。

区分即梦界面、即梦同源 API 和火山方舟 Seedance 服务。会员不等于 API 权限、余额或相同模型效果。用户只要剧本、图片或接入方案时，不自动提交付费任务；已明确授权的生成范围内继续执行，不重复索取许可。

为每个镜头保存提示词、参考图、候选版本、任务 ID 和状态。提交超时先查任务，无法确认是否创建时标记 `unknown` 并停下该任务的重提，不盲目重复计费。其余独立镜头可继续。重试次数在执行前按用户范围或预算设上限，不无限重抽。

### 4. 剪辑与交付

先固定角色声音和对白节奏，再处理口型、字幕、环境音、配乐和剪辑。语音合成需要单独能力，Codex 编写台词不等于已生成音频。

按镜头清单选择候选版本并生成初剪。剪映社区草稿工具与剪映官方能力分开说明；草稿写入、应用打开、渲染导出分别核验。未经版本实测，不承诺最新版剪映或 macOS 能全程 CLI 导出。

不支持自动导出时交付可用草稿或按序素材、字幕与操作指引；用户同意替代合成路径时可用 FFmpeg 输出 MP4，但不承诺复现剪映专属特效，不默默替换剪映。

## 质量与交付状态

| 检查点 | 验收内容 |
|---|---|
| 角色与场景 | 脸、服装、画风、道具和空间关系连贯 |
| 动态镜头 | 无明显变形、闪烁、穿模、重复人物或动作中断 |
| 叙事与声音 | 镜头顺序、对白停顿、字幕时间与口型匹配 |
| 工程与成片 | 素材路径可解析；草稿能打开；导出视频可播放且有预期音轨与时长 |

只报告实际达到的阶段：剧本完成、提示词完成、图片已生成、视频已下载、草稿已写入、草稿已打开、成片已导出。未执行的检查标明未验证。

交付实际文件路径、选用镜头清单、缺失素材和下一步。生成素材时记录可用镜头数、尝试次数、已知费用与耗时；没有账单数据时不推算为实际费用。
