# 参考片研究与经验迁移

用户要求借鉴作品的策划、分镜、布景、镜头转换或声音时使用。先读取已有研究；需要新检索时使用当前可用搜索能力及其访问规则。研究不隐含下载、媒体复用或生成授权。

## 先说明有什么证据

| 材料／方法 | 可支持的结论 | 尚不能确认 |
|---|---|---|
| 截图 | 可见构图、造型、文字、光色与姿态 | 运镜、口型、流畅度、切换节奏与声音 |
| 局部连续片段 | 该时间范围内的动作、镜头变化与同步（声音可听时） | 全片规律与片段外事实 |
| 全片定时抽帧／联系表 | 已采样位置的内容、段落和视觉重复元素 | 未采样瞬间、精确切点与完整连续运动 |
| 检测器／信号测量／分类器 | 指定方法下的候选与数值 | 已经人工验收的镜头数、曲风或乐器 |
| 创作者采访／用户反馈 | 有明确归属的制作自述与评价 | 每个镜头的实际做法、独立验证或传播因果 |

报告分开写观察事实、文件测量、外部自述和本次解释／建议。说明素材版本、覆盖范围、未完成的试听或人工复核，不将有文件等同于已经完整看过、听过。

## 画面与声音怎么拆

- 先标主要段落和各人物作用，再观察空间、表演、听者反应、景别、字幕与段落收束。用时间位置提供复核入口，约值明确标注。
- 全片抽样用于找结构，切换候选用于找复核点；关键运动和情绪转折补看连续片段。固定帧步长需结合实际帧率解释，变帧率素材优先按时间抽样。
- 场景检测的相邻候选可能来自闪光、快速运动或同一变化的重复触发。人工核对前不把候选数量当镜头总数，不直接据此计算正式平均镜长，也不机械扣除短间隔后宣布精确结果。
- 分开描述稳定构图、可见移动和后期转换。仅凭成片不能确定某次运动由模型、拍摄还是后期完成，也不能反推真实焦距、灯具或原始工程。
- 音频先核对容器、音轨、时长和来源；无直接听辨能力时明确说明。节奏自相关可能有半速／倍速歧义，分类标签不等于细分曲风或乐器鉴定；响度不等于速度，RMS不等于LUFS，分类置信分数不等于准确率。
- 未试听和精细对轴前，不宣布已确认唱句、换气与切点同步。混音不等于干声或分轨；参考片的BPM、响度与乐器不自动成为新作规格。

## 迁移方法，不复制成片配置

将经验写成“观察到的组织—可能作用—本片怎样采用—约束或待验证项”。例如歌者与听者往返，可以迁移为有依据的反应镜头；不能因此规定每片必须酒馆布景、多人哭泣或固定切换频率。

点赞、弹幕与单案例不能证明某个做法导致走红。受众反馈与传播效果另行记录；没有对照证据时使用“可尝试”“本次判断”，不承诺爆款。具体人物、场景、比例、时长、音色与数值参数留在项目，除非用户明确选为当前规格。

## 来源、恢复与边界

在作品项目记录来源页面、作品与作者标识、实际下载来源、获取日期、文件路径、大小、SHA256、提取关系及工具版本。只在用户授权且来源允许访问时下载；访问受限时不自动登录或绕过。不把公开可见当转载、商用、声线克隆或生成输入的授权。

大媒体遵循项目Git策略。需要跨设备恢复时，在项目提供公开地址、校验清单与恢复入口，说明地址可能失效，并保留单独备份建议；不将案例专用下载器复制成skill的固定依赖。源片哈希用于确认版本，派生文件记录本机实际哈希，封装或编码工具变化可能改变其字节。

可分享清单不存Cookie、密钥或带凭据的临时链接。重跑输出与历史研究快照分开，审核差异后再更新结论；引用项目相对路径，不硬编码研究者机器目录。
