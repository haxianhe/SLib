# Knowledge Sync

把本地 Markdown 写入外部文档系统。核心原则：**目标明确、内容可见、确认后写、结果可核验**。

## 输入契约

至少收集：

| 信息 | 要求 |
|---|---|
| 本地内容 | 文件路径或用户直接提供的 Markdown |
| 目标连接器 | 用户指定的平台；不得从“任何能用的”服务中擅自选择 |
| 目标位置 | 工作区、知识库、文件夹或父文档 |
| 写入方式 | 新建、覆盖、追加或更新指定文档 |
| 可见范围 | 私有、指定成员或组织范围；无法判断时必须询问 |

只读检查当前环境已经提供的文档连接器。不要安装插件、创建账号或修改连接配置。没有可用连接器时停止，并说明需要用户先连接支持文档写入的服务。

## 写入协议

1. 读取本地内容，确认文件存在且可读；不得把读取失败当成空文档。
2. 识别凭据、个人信息、内部链接和明显机密字段，提醒用户确认是否保留或脱敏。
3. 展示写入计划：
   - 连接器、账号或工作区；
   - 目标位置和新建/更新方式；
   - 文档标题、可见范围；
   - **内容预览**：短文展示全文，长文展示首段、目录、字数和敏感项提示。
4. 请求用户对上述计划作出**明确确认**。即使用户说“别再问”，目标含糊、外部披露或覆盖已有内容时也不能跳过。
5. 只调用已确认的连接器和目标。不要顺带创建其他文档、改变共享权限或通知无关人员。
6. 写入后读取连接器返回值，核验文档 ID、URL 或更新时间，再报告结果。

## 失败语义

- 用户拒绝：报告“未同步”，不执行外部写入。
- 无连接器或未授权：报告缺少的能力和配置入口，不自动安装。
- 写入或核验失败：报告“同步失败/结果未确认”，保留本地文件。
- 只有连接器明确返回并完成核验后才能说“同步成功”；其他情况下**不得声称成功**。

## 结果格式

成功时返回连接器、目标位置、写入方式、文档链接或 ID。失败时返回未执行的步骤、错误原因和安全的重试建议，不在错误消息中回显敏感正文或凭据。
